🚀 Spam Email Detection Chatbot | NLP + Machine Learning

Excited to share my latest project — Spam Email Detection Chatbot! 🤖📧
Built using Python, NLP, TF-IDF, Machine Learning, Flask, React.js, and OpenAI API.

The application analyzes email content and classifies it as SPAM or NOT SPAM, with an interactive React-based chatbot interface.

This project helped me gain hands-on experience in NLP, Machine Learning, API development, and AI integration. 🚀
